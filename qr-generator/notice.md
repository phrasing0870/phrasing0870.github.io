This tool's feature design and core logic (QR generation options, WiFi/vCard
encoding, logo overlay, styled export) were ported and adapted from
delphi.tools' QR code generator, originally written in TypeScript/React and
published under the MIT License below. This version was rewritten as a
standalone HTML/CSS/JS implementation (no build step, no framework) to match
the rest of EGRelay's tools, but the underlying design and logic derive from
that source.

Original repository: delphi.tools (QR code generator)
