Detected metadata

Images are scrubbed by redrawing them onto a canvas and re-exporting, which drops all EXIF, GPS, and embedded color profile data by construction. Orientation is baked into the pixels first, so the output still looks correct. PDFs are scrubbed by clearing the document info dictionary (author, creator, producer, timestamps) and removing the document-level XMP metadata stream. This does not remove metadata in annotations, attachments, embedded objects, or JavaScript, and is not a full PDF sanitization tool. No file ever leaves your device.
